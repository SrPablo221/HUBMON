# Segurança

Este é um aplicativo desktop local. Para reportar uma vulnerabilidade, evite publicar detalhes exploráveis em uma issue aberta. Se o projeto ainda não tiver um canal privado de contato configurado no GitHub, contate primeiro o mantenedor por um canal que ele tenha publicado no perfil do projeto.

Nunca envie senhas, tokens, dados de conta PlayStation ou outros segredos. O HUBMON não precisa dessas informações.
