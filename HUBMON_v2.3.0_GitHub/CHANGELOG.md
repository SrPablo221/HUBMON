# Histórico de versões

## 2.3.0 — preparação para publicação pública

- Alinhados o número de versão da interface e o cabeçalho do código.
- Criado instalador que usa um ambiente virtual Python local (`.venv`).
- Adicionado inicializador mais claro e script de testes para Windows.
- Criada documentação de instalação, compatibilidade, privacidade e limitações.
- Adicionados modelos de issues, instruções de contribuição, workflow de testes e licença.
- Mantidos os recursos existentes: troca de entrada, brilho, volume/mute quando suportados, perfis locais e biblioteca manual de jogos.

### Limitações conhecidas

- Ainda não há executável `.exe`.
- Os controles físicos precisam de validação por modelo de monitor.
- A biblioteca não detecta nem inicia jogos no PS5.
